#### Requirements

* Git

* neovim >= 0.11.3

* clangd (c/c++ lsp)

* lua-language-server (lsp)

#### Getting Started

* Clone the repo:

```sh

git clone https://github.com/BBIAntares/nvim-config ~/.config/nvim

```

* Remove the .git folder:

```sh

rm -rf ~/.config/nvim/.git

```

* Start nvim:

```sh

nvim

```

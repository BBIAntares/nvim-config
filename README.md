#### Requirements

* Git

* neovim >= 0.11.3

* rust-analyzer & rust-src

* lua-language-server (lsp)

* tree-sitter-cli

* gcc (for treesitter-cli)

#### Getting Started

* Clone the repo:

```sh

git clone https://github.com/BBIAntares/nvim-config ~/.config/nvim

```

* Remove the .git folder:

```sh

rm -rf ~/.config/nvim/.git

```

* Start nvim:

```sh

nvim

```
